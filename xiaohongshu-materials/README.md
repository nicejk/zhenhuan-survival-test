## 三、素材真实性说明

- **03、04 的页面截图来自线上真实站点**（https://gongdou-test.netlify.app），通过无头 Chrome 实际走完「输入兑换码 → 答 25 题 → 出结果」流程后截取，不是 AI 生成或拼接的假页面。
- 04 中的结果数据（21 集 / 叶澜依型｜不驯的野马 / 生存力 44.6 / 死因「说得太多」）是真实跑出的样本，图片上已标注「示例结果」，未作为用户案例宣传。
- 02 的六维名称、含义与「12 种原型」「25 道题」均取自项目数据文件（`shared/questions.js`、`shared/archetypes.js`、`shared/scoring.js`）。
- 04 中「完整版报告」的章节名称取自 `src/components/ReportBody.jsx`：生存画像、六维逐项深读、三个高风险时刻、现实中的三个角色、30 天微调计划。
- 所有图片与文案均未出现真实兑换码、Supabase 密钥、后台地址或任何用户数据。
