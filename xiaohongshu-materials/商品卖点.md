# 商品卖点（5 个核心）

## 1. 不是抽签，是算出来的

25 道情境题按六个维度计分，再加权换算成 1–76 的集数。你选了什么，决定你落在哪一集。

## 2. 不给你一个标签，给你一张结构图

结果有集数、死因、12 种原型之一，还有六维雷达图和逐项分数，并标出最强项与短板。看得见「哪里强」，也看得见「输在哪」。

## 3. 完整版报告不用另外付费

除结果页本身的解读外，还能展开完整版：生存画像、六维逐项深读、三个高风险时刻、现实中的三个角色、30 天微调计划。

## 4. 一个码 3 次，能看自己的变化

同一兑换码最多测 3 次，多次结果会自动放在一起对照，显示集数变化和维度差异，而不是重复做同一件事。

## 5. 0.99 元，打开链接就能测

手机浏览器直接答题，不用下载 App、不用注册账号。首次使用后 7 天内有效，页面会显示剩余次数。
